siłka – animacje

Subtelne animacje pasujące do design systemu: lift hantli, glow pomarańczu, reveal tekstu. Gotowe SVG z wbudowanym CSS.

01. Header – subtle hover (produkcyjne)

Najedź myszką – lekki lift + glow #FF6B35. Wdrożone w top-menu.component.css

@keyframes silka-lift { 0%,100% { transform: translateY(0) scale(1.05); } 50% { transform: translateY(-2px) scale(1.07); } } .sfc-header__logo:hover img { animation: silka-lift 0.6s ease-in-out; filter: drop-shadow(0 0 8px rgba(255,107,53,0.4)); }

Hantla unosi się co 1.8s + pulse glow. Do hero, loading screen.
